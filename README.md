# Ixhuatán & Beyond — Guatemala Family Trip 2026 🇬🇹

Aplicación interactiva y visual diseñada para planificar, visualizar y organizar un viaje familiar y de amigos de 27 días (del 15 de noviembre al 11 de diciembre de 2026) a través de Guatemala y El Salvador.

Base del viaje: **Santa María Ixhuatán, Santa Rosa, Guatemala**.

---

## 🌟 Características Principales

- **🌐 Totalmente Bilingüe (Español / English):** Cambio instantáneo de idioma con un clic para que visitantes de EE.UU. (Bruce y Norma) y la familia local disfruten la experiencia por igual.
- **🗺️ Mapa Interactivo en Tiempo Real:** 
  - Trazado de rutas por polilíneas con colores distintivos por fase.
  - Filtros para visualizar y comparar las opciones de Thanksgiving y de Diciembre.
  - Burbujas informativas de carretera con tiempos de manejo, distancias y calidad del camino.
  - Itinerario secuencial paso a paso de cada ruta con desglose de lugares a visitar y paradas técnicas intermedias.
  - Capacidad de agregar o editar lugares de interés y paradas directamente desde el mapa.
- **📅 Itinerario Día a Día (27 Días):** Cronograma completo desde la recogida en el Aeropuerto La Aurora el 15 de Noviembre a las 2:30 PM hasta el vuelo de regreso el 11 de Diciembre. Con filtros por hitos, playa, descanso en casa y viajes largos.
- **⚖️ Comparador de Opciones & Sistema de Votos:**
  - **Thanksgiving (25 - 30 Nov):** Opción 1 (El Salvador: Ruta de las Flores & Coatepeque) vs. Opción 2 (Caribe: Río Dulce & Chiquimula) vs. Opción Híbrida.
  - **Diciembre (3 - 7 Dic):** Opción A (Atitlán & Antigua - Recomendada para todas las edades) vs. Opción B (Semuc Champey & Cobán - Aventura 4x4).
  - Votación interactiva con lluvia de confeti y persistencia en navegador.
- **🎒 Centro de Equipaje & Clima Inteligente:** Listas de equipaje por microclima (playa, altiplano, selva) con kits especiales para bebé de 7 meses (Emily) y adultos mayores (60s y 70s).
- **👥 Directorio de Contactos & Emergencia:** Tarjetas familiares y números de asistencia turística (INGUAT 1500, Policía 110, Bomberos 122).
- **💾 Exportación e Importación:** Respaldo completo del estado en formato JSON.

## 🚀 Tecnologías

- **React 18** + **TypeScript**

- **MapLibre GL** (Mapas interactivos vectoriales)
- **Lucide React** (Iconografía limpia)
- **Canvas Confetti** (Efectos visuales interactivos)

## 💻 Instalación y Desarrollo Local

1. **Clonar el repositorio:**
   ```bash
   git clone <url-del-repositorio>
   cd ixhuatan-and-beyond
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:5173](http://localhost:5173) en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
